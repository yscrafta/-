# 売上管理表作成ツール

## プロジェクト概要
- **名前**: 売上管理表作成ツール
- **目的**: AirHostのCSVファイルから売上管理表（Excel形式）を自動生成
- **主な機能**: 
  - 全施設CSVファイルのアップロード
  - 施設の自動検出と選択
  - 施設ごとまたは全施設統合での売上管理表作成
  - 指定月の予約データ抽出
  - Excelファイルの自動生成とダウンロード
  - 販路別データ整理
  - 言語・国籍の自動判定

✅ **施設自動検出**: CSVから施設情報を自動抽出  
✅ **施設選択機能**: 個別施設または全施設統合を選択可能  
✅ CSVファイルのアップロード機能

## データ構造
### 入力データ（CSV）
- 予約サイト、チャンネル予約ID、チェックイン、チェックアウト
- ゲスト名、国籍、ゲスト数、合計日数
- 販売金額、OTAサービス料、受取金、クリーニング代
- 状態（確認済み、システムキャンセル等）

### 出力データ（Excel）
- 言語、国籍、販路
- ゲスト名（予約ID付き）
- 予約日、チェックイン、チェックアウト
- 滞在日数（計算式）
- 人数、支払金額
- ADR、客単価（計算式）
- OTAサービス料

## 使用方法
1. AirHostから予約データをCSV形式でエクスポート（全施設データ）
2. ウェブページでCSVファイルをアップロード
3. 施設が自動検出され、選択肢が表示される
4. 対象施設を選択（個別施設または「全施設（統合）」）
5. 対象の年月を選択（例: 2025年11月）
6. 「売上管理表を生成」ボタンをクリック
7. 自動的に選択した施設のExcelファイルがダウンロードされる
